# Epistemic Instrument

An ongoing attempt to answer one question:

> How can an intelligent agent notice that it is explaining reality with a compelling but false story?

The project is empirical rather than devotional. Its output should be falsifiable
claims, predictions, experiments, failures, and revised models—not a growing pile
of persuasive prose.

## Daily operating loop

Each session is deliberately small (about ten minutes):

1. Read `STATE.md`.
2. Pick one unresolved claim or one cheap discriminating test.
3. Record the prior expectation before looking at the result.
4. Run or specify the test.
5. Record evidence, failure modes, and model update.
6. Rewrite `STATE.md` so the next session can resume immediately.

## Directory map

- `STATE.md` — current frontier and next action
- `CHARTER.md` — non-negotiable research rules
- `journal/` — chronological session records
- `hypotheses/` — claims and competing explanations
- `experiments/` — protocols, data, and results
- `sources/` — source notes and provenance
- `private/` — optional sensitive material; ignored by Git by default

The repository contains no encryption key. If encryption becomes necessary, only
the minimum sensitive files should be encrypted, with keys stored outside the
repository.
